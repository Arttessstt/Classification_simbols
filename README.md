# Адаптивная Полносвязная Нейронная Сеть для Классификации Символов (на языке C)

## Обзор проекта
Данный проект представляет собой реализацию гибкой и оптимизированной нейронной сети, написанной на чистом языке C. Основная задача сети — классификация рукописных символов (например, цифр из набора данных MNIST).

Проект разработан с учетом высоких стандартов программирования, включает многопоточные вычисления, механизмы регуляризации и аугментации данных для достижения максимальной устойчивости и производительности.

## Ключевые особенности
*   **Динамическая архитектура:** Возможность изменять количество слоев и нейронов через файл `config.txt` без перекомпиляции кода.
*   **Многопоточность (POSIX Threads):** Вычисления прямого прохода распараллелены для ускорения работы с большими слоями.
*   **Продвинутая математическая база:**
    *   Функции активации: **ReLU** для скрытых слоев и **Softmax** для выходного.
    *   Алгоритм обучения: **Stochastic Gradient Descent (SGD)**.
    *   Предотвращение переобучения: **L2-регуляризация**.
    *   Инициализация весов: Метод **Xavier/He** для стабильного старта обучения.
*   **Устойчивость к шумам:** Встроенный генератор шума (5-10% искажения пикселей) и аугментация (случайные повороты изображений).
*   **Визуализация:** Экспорт активаций скрытых слоев в `heatmap.txt` и истории обучения в `loss_history.csv`.

## Структура проекта
*   `main.c` — Основной цикл управления: загрузка данных, цикл обучения и оценка результатов.
*   `neural_net.c / .h` — "Сердце" системы: реализация слоев, прямого и обратного распространения ошибки, многопоточность.
*   `config_parser.c / .h` — Модуль для чтения настроек из `config.txt`.
*   `data_loader.c / .h` — Загрузка CSV-данных, добавление шума и аугментация (повороты).
*   `utils.c / .h` — Вспомогательные функции (ReLU, Softmax, Cross-Entropy).
*   `Makefile` — Сценарий сборки проекта.
*   `config.txt` — Файл конфигурации архитектуры и гиперпараметров.

## Инструкция по запуску

### Требования
*   Компилятор GCC.
*   Утилита Make.
*   Библиотека `pthread` (стандартная для POSIX-систем, включена в MinGW на Windows).

### Сборка
Откройте терминал в папке проекта и выполните команду:
```bash
make
```

### Запуск
После успешной сборки запустите исполняемый файл:
```bash
./neural_net_app.exe
```

## Настройка (config.txt)
Вы можете редактировать параметры сети в файле `config.txt`:
*   `neurons`: Список через запятую (Входной слой, Скрытые слои..., Выходной слой). Например: `784, 128, 64, 10`.
*   `learning_rate`: Скорость обучения (рекомендуется `0.001` - `0.01`).
*   `regularization`: Коэффициент L2-регуляризации (рекомендуется `0.01`).

## Этапы разработки проекта

Процесс создания данной системы был разделен на несколько ключевых фаз, каждая из которых направлена на обеспечение качества и производительности:

1.  **Исследование и проектирование (Research):** 
    *   Анализ математических основ нейронных сетей (алгоритм Backpropagation, градиентный спуск).
    *   Проектирование модульной структуры для разделения логики обучения, загрузки данных и математических вычислений.
2.  **Разработка ядра (Implementation):**
    *   Реализация базовых структур данных для слоев и весов.
    *   Написание функций прямого и обратного распространения ошибки.
    *   Создание парсера конфигурации для обеспечения гибкости архитектуры.
3.  **Оптимизация и параллелизм (Optimization):**
    *   Внедрение многопоточности через **POSIX Threads** для ускорения матричного умножения.
    *   Применение метода инициализации Xavier для более быстрой сходимости сети.
4.  **Обработка данных и устойчивость (Data Processing):**
    *   Реализация механизмов аугментации (повороты) и зашумления.
    *   Добавление L2-регуляризации для борьбы с переобучением.
5.  **Тестирование и валидация (Testing):**
    *   Отладка на синтетических данных для проверки корректности градиентов.
    *   Финальное тестирование на датасете MNIST.
6.  **Финальное документирование:**
    *   Написание подробных комментариев для каждой функции.
    *   Подготовка отчетных файлов и данного руководства.
